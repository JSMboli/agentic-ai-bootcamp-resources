# Agentic AI Bootcamp — Reliable Providers v3

**Delivery:** 18–26 August 2026 (five teaching days; Thursday 20 August is the Amazon fulfilment-centre industrial visit).

This revision rebuilds the practical layer around reliable Groq/Ollama diagnostics, observable model calls, LangGraph workflows, tools, RAG and genuine Human-in-the-Loop interrupts.

## Start here

1. Read `resources/PROVIDER_ACCOUNT_SETUP.md`.
2. Follow `resources/SETUP_GUIDE.md`.
3. Copy `resources/.env.template` to `resources/.env` and add only the keys you intend to use.
4. Restart Jupyter, then run `resources/notebooks/Day_0_Setup_and_Provider_Check.ipynb` from the top.
5. Continue Day 1 through Day 5 in order.

## Important files


- `resources/PROVIDER_TROUBLESHOOTING.md` — Groq/Ollama and kernel/path troubleshooting matrix.
- `resources/PROVIDER_ACCOUNT_SETUP.md` — account/API-key instructions for Groq, Ollama, OpenAI, Gemini, Anthropic and DeepSeek.
- `One_Week_Programme_Outline.md` — teaching programme.
- `slides/` — expanded slide decks.

## Security

No live `.env`, API key, copied virtual environment or Jupyter checkpoint is distributed in this v3 package. If a credential has previously appeared in chat, notebook output or another ZIP, revoke it and create a new one.
